## 💻 Run Locally

Clone this repository:

```bash
git clone https://github.com/uzairDev8/sheikhPortfolio.git
```

Open the project folder:

```bash
cd sheikhPortfolio
```

Install dependencies:

```bash
npm install
```

Start the Angular development server:

```bash
ng serve
```

Open `http://localhost:4200/` in your browser.
